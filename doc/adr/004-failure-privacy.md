# ADR-004 — Failed-row privacy and retention

- Status: Accepted
- Date: 2026-09-16

## Decision

Failed-row payloads are private operational data. BulkFlow redacts configured
secret-like attributes before persisting a payload or generating an error report.
Import APIs are guarded by application-provided authorization and scope hooks;
the package does not assume a user or tenancy model.

Materialized `fromDisk()` sources remain in private application storage until a
consumer's retention policy removes them. Disk exports use Laravel temporary URLs
only when the selected disk supports them. Public URLs are never generated by
default.

## Consequences

- Consumers must configure authorization/scoping and a storage/run retention
  schedule appropriate for their data classification.
- Reports should be stored on private disks and shared through temporary URLs.
- Error exports and retained sources must not be committed, copied into fixtures,
  or published as package artifacts.
