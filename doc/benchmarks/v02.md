# V0.2 large-import benchmark

## Reproducible run

Date: 2026-09-21

Command, executed in the demo application's isolated SQLite benchmark environment:

```bash
php artisan --env=benchmark bulkflow:benchmark-import \
  --rows=100000 --chunk=1000 --queued --sync
```

Latest observed result (re-run from a fresh isolated SQLite database):

```json
{
  "rows_requested": 100000,

```

The benchmark uses the same queued dispatcher and Laravel Bus batch path as production. `--sync` makes the demo wait for completion; production should use a real queue worker. CSV jobs use byte ranges, while XLSX jobs use temporary streamed chunk files. Valid rows in a chunk are persisted with a bulk insert/upsert; a batch database error falls back to individual rows so failure records remain actionable.

These numbers are environment-specific and are a regression reference, not a cross-machine performance guarantee.
