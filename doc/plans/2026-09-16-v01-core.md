# BulkFlow V0.1 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** انتشار یک Laravel package قابل‌آزمون که CSV/XLSX را با mapping، transform، validation و create/insert/upsert وارد و صادر می‌کند.

**Architecture:** تمام فرمت‌ها از قرارداد `Reader`/`Writer` عبور می‌کنند و `ImportDefinition` immutable تنظیمات Builder را نگه می‌دارد. `SyncImportRunner` ردیف‌ها را به `RowPipeline` می‌فرستد و از `PersistenceStrategy` برای ذخیره استفاده می‌کند؛ فعلاً هیچ queue/UI/database run-history وارد این نسخه نمی‌شود.

**Tech Stack:** PHP 8.2+، Laravel 11/12، Orchestra Testbench، PHPUnit، OpenSpout، Eloquent، Laravel Validator.

**Spec:** [../PRD.md](../PRD.md)

## Global Constraints

- فقط CSV و XLSX؛ API reader/writer باید برای driver جدید قابل توسعه بماند.
- هر reader باید iterator/lazy iterable از `SourceRow` بدهد؛ هیچ `array` شامل کل فایل برنگرداند.
- validation پس از mapping و transform اجرا می‌شود.
- `run()` synchronous است و `queue()` در V0.2 اضافه می‌شود.
- خطاهای ردیفی در V0.1 فقط در `ImportResult` بازگردانده می‌شوند؛ persistence خطاها V0.3 است.
