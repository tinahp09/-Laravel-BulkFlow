# BulkFlow V0.2 Large Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** اجرای import/export حجیم به‌صورت chunked و queued با retry قابل‌پیش‌بینی و benchmark حافظه.

**Architecture:** V0.1 pipeline بدون تغییر معنایی در jobهای chunk اجرا می‌شود. `QueuedImportDefinition` فقط دادهٔ serializable دارد؛ `RunStore` موقت V0.2 وضعیت batch و شمارنده‌ها را نگه می‌دارد تا V0.3 آن را به persistence کامل ارتقا دهد.

**Tech Stack:** V0.1 + Laravel Queue، Bus Batch، Cache/Database، PHPUnit.

**Spec:** [../PRD.md](../PRD.md)

## Tasks

### Task 1: Serializable definition و chunk planner

**Files:** Create `src/Queue/{QueuedImportDefinition,ChunkPlanner}.php`, `tests/Unit/ChunkPlannerTest.php`.

- [ ] Test بنویسید که 2,501 row با `chunkSize(1000)` به offsetهای `0,1000,2000` می‌شکند و definition شامل closure نیست.
- [ ] test failure را اجرا کنید، سپس `ImportBuilder::chunkSize(int)` و `queue()` را فقط با transformerهای class-string/serializable value object فعال کنید.
- [ ] `ChunkPlanner` را implement کنید و `vendor/bin/phpunit tests/Unit/ChunkPlannerTest.php` را PASS کنید.

### Task 2: Batch orchestration و progress counters

**Files:** Create `src/Queue/{DispatchImportBatch,ProcessImportChunk,RunState}.php`, `tests/Feature/QueuedImportTest.php`.

- [ ] Queue/Bus fake test بنویسید که `queue()` یک batch با chunk jobهای درست dispatch و state `queued` می‌سازد.
- [ ] job را implement کنید تا همان `RowPipeline` و persistence strategy V0.1 را فقط برای بازهٔ assigned اجرا کند و `processed/successful/failed/skipped` را atomically افزایش دهد.
- [ ] test را PASS کنید؛ result state باید پس از پایان همهٔ jobها `completed` یا `completed_with_errors` شود.

### Task 3: Retry و idempotency

**Files:** Modify `src/Queue/ProcessImportChunk.php`; Create `src/Queue/RetryPolicy.php`, `tests/Feature/ChunkRetryTest.php`.

- [ ] test transient reader exception با `tries=3` و `backoff=[5,30]` بنویسید و assert کنید exception پس از مصرف tries به batch failure می‌رسد.
- [ ] test upsert rerun بنویسید که اجرای دوبارهٔ همان chunk رکورد duplicate نمی‌سازد.
- [ ] `RetryPolicy` و job middleware را implement کنید؛ validation row failure نباید job retry شود.
- [ ] suite queue را PASS کنید.

### Task 4: Memory/timeout safeguards و benchmark

**Files:** Create `src/Support/MemoryGuard.php`, `tests/Integration/LargeCsvImportTest.php`, `bin/benchmark-import`, `doc/benchmarks/v02.md`.

- [ ] fixture 10k row و test iterator بنویسید که runner کل input را array نمی‌کند.
- [ ] memory guard را implement کنید تا نزدیک `memory_limit` job را با `ImportInfrastructureFailure` متوقف کند؛ timeout/tries/backoff از config خوانده شوند.
- [ ] benchmark 10k و 100k را اجرا و زمان/peak memory/chunk size را ثبت کنید؛ regression budget را در CI nightly قرار دهید.

### Task 5: V0.2 release gate

- [ ] README queue setup، worker command و idempotency caveat را اضافه کنید.
- [ ] 100k demo import را با queue driver منتخب اجرا و summary را مستند کنید.
- [ ] suite، static analysis و formatter را PASS؛ changelog `0.2.0-alpha` را آماده و commit کنید.
