# BulkFlow V0.4 Vue UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** یک Vue 3 package مستقل برای انتخاب فایل، mapping، شروع run، progress و مشاهده/retry failureها.

**Architecture:** پکیج `@bulkflow/vue` فقط با یک `BulkFlowClient` typed صحبت می‌کند. Laravel package action/service می‌دهد و HTTP adapter opt-in در application لایهٔ نازکی روی آن است؛ هیچ policy یا validation domain در Vue تکرار نمی‌شود.

**Tech Stack:** Vue 3، TypeScript، Vite، Vitest، Vue Testing Library، Laravel HTTP tests.

**Spec:** [../PRD.md](../PRD.md)

## Tasks

### Task 1: HTTP contract و typed client

**Files:** Create `src/Http/*`, `packages/vue/src/client.ts`, `packages/vue/src/types.ts`, Laravel/Vitest contract tests.

- [ ] request/response schema برای preview/create/run/failures/retry/report را با pagination و error envelope ثابت بنویسید.
- [ ] Laravel adapter را روی serviceهای V0.3 implement کنید و authorization resolver را از request actor دریافت کنید.
- [ ] mock-server Vitest بنویسید تا `BulkFlowClient` request/response و error mapping را تأیید کند.

### Task 2: Import wizard و mapping

**Files:** Create `packages/vue/src/components/{ImportWizard,FileStep,MappingStep,ConfirmStep}.vue`, component tests.

- [ ] test مسیر file→preview→mapping→confirm را بنویسید؛ header بدون destination باید قبل از submit خطا بدهد.
- [ ] componentها را با slots/theme tokens و keyboard focus implement کنید.
- [ ] testهای validation و upload error را PASS کنید.

### Task 3: Progress و error viewer

**Files:** Create `packages/vue/src/components/{ImportProgress,ErrorViewer}.vue`, composables, tests.

- [ ] test polling progress تا completion و نمایش summary/failure pagination بنویسید.
- [ ] retry selection، download report و empty/permission-denied state را implement کنید.
- [ ] testها را PASS و accessibility keyboard assertions اضافه کنید.

### Task 4: V0.4 release gate

- [ ] Story/demo app، npm build، API integration test و docs installation/theme را کامل کنید.
- [ ] changelog `0.4.0-alpha` و compatibility peer dependencyها را ثبت کنید.
